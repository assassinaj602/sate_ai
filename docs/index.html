11 Fault Injectors

Memory

MemoryPressureInjector

Injects artificial RAM allocation pressure up to limit MB.

Validation

MalformedInputInjector

Feeds empty, oversized (1MB), and binary garbage inputs.

Quantization

QuantizationDriftInjector

Simulates cumulative precision degradation over repeated steps.

Thermal

ThermalThrottleInjector

Simulates mobile device CPU throttling and heat step escalation.

Performance

LatencyInjector

Injects artificial latency delays to test fallback paths.

Fallback

ModelSwapInjector

Swaps model quality dynamically to evaluate alternative runtimes.

Network

NetworkLatencyDropInjector

Simulates network latency drops, timeouts, and disconnections.

Confidence

ConfidenceThresholdInjector

Validates confidence threshold boundaries on predictions.

VRAM

GpuMemoryPressureInjector

Simulates GPU VRAM exhaustion scenarios.

I/O

DataCorruptionInjector

Injects noise, blur, and bit glitches into input payloads.

Version

ModelVersionMismatchInjector

Simulates model schema mismatches and fallback handlers.

CLI Quick Reference

Execute stress tests, benchmarks, batch jobs, health checks, and history queries from command line.

Basic Stress & Retry 
sate_ai --model model.gguf --injectors memoryPressure,malformedInput --retry 3 --flaky-threshold 2
Benchmark Mode & Batch Auto-Detect 
sate_ai --model model.gguf --benchmark --benchmark-runs 20
sate_ai --models model1.onnx,model2.tflite,model3.gguf --auto-detect
SQLite Storage & History Query 
sate_ai --model model.gguf --db reports.db
sate_ai --db reports.db --db-history all
SVG Status Badges & Custom Templates 
sate_ai --model model.gguf --badge badge.svg --badge-type status
sate_ai --model model.gguf --template templates/slack.yaml --output custom_report.json
