# Changelog

All notable changes to the SATE AI DevTools plugin will be documented in this file.

## [0.1.0] - 2026-09-02

### Added
- Initial release of SATE AI DevTools plugin (`sate_ai_devtools`).
- Custom tab in Flutter DevTools.
- Run stress tests directly from DevTools.
- Real-time metrics display (Total, Passed, Failed, Duration).
- Baseline management (Save as Baseline & Compare Baseline).
- Log viewer console with color-coded status messages.
